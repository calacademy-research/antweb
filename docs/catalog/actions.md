## Columns

- **Access**: the check the generator found. `public` (no check, no sign of writing data), `logged-in`, `curator`, `admin`, `system` (the nightly scheduler's secure code or AntWeb's own call), `admin or system`, `partial` (checks found only on some paths, e.g. the save branch of a public page; read the evidence), `no check found` (the class shows signs of changing data or uses the login but no check was found). Where: `class` (Java), `jsp` (an included adminCheck/curatorCheck/loginCheck; it runs after the Java class). This is a static reading of the code; `conditional` checks only apply on some paths.
- **Anon**: what an anonymous request without parameters gets on staging (tests/e2e/expectations.json).
- **E2E**: functional end-to-end tests that request this URL. `probe` = only the anonymous probe in test_actions.py (bare URL, no login); `never` = listed in policy.NEVER (not requested by the suite).
- **Status**: keep, check (cannot tell from the code), remove? (looks unused; reason in notes), removed (taken out; the row is kept with access `removed` and the e2e test that checks it stays gone).
