AntWeb's software is brought up to current, supported versions, and several long-standing issues are fixed. Thanks to everyone who contributed since 9.0.0: Sathya (@Sathyavrv), Gladrin (@Gladrin22), Antony (@antony-jr) and Brian Fisher (@bpescador).

### For everyone
- AntWeb runs on current software: Java 21, Tomcat 11, MySQL 8.4, Ubuntu 24.04.
- Login and account creation are more secure; existing passwords keep working.
- Country and region species lists and counts are rebuilt every night again.

### For curators
- **Specimen List Lookup**: codes not found in AntWeb, and codes containing spaces, are listed on a results page ready to copy or download. Data for every code that was found can still be downloaded.
- **Specimen uploads**: records under a genus that AntCat has synonymized move to the current valid genus; named species take AntCat's current combination (for example *Wasmannia auropunctata* becomes *Allomerus auropunctatus*). These are listed in the upload report instead of being refused.
- **Upload reports** say whether an upload was made from the upload page or by an automatic job.
- **New species** uploaded before AntCat published them get their Taxonomic History and distribution with the next nightly AntCat update.
- **CAS specimens** are updated from TaxonWorks every night.

The full list is in [CHANGELOG.md](https://github.com/calacademy-research/antweb/blob/master/CHANGELOG.md) and below.
