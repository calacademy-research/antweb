AntWeb 9.4.0 introduces API version 4, improves geographic and taxonomic reporting, and adds new tools for monitoring imaging coverage, managing specimen data, and verifying database exports.

A major improvement is the ability to retrieve complete, paginated specimen datasets through the API. The release also improves the treatment of oceanic islands, which are now represented as separate geographic units where appropriate.

### Improvements for all users
- **Oceanic islands as separate geographic units.** Hawaii and the Galápagos Islands now have their own country-level pages in AntWeb, reflecting their distinctive ant faunas. Their species lists, specimen counts, and downloads are no longer included in those of the United States and Ecuador, respectively. The parent-country pages explain these exclusions.
- **Improved endemic species counts.** Endemic status now also counts the type localities recorded in AntCat, alongside AntWeb's specimens. A valid species listed from only one country is identified as endemic there, based on currently available data. The Galápagos Islands now have 28 species classified as endemic.
- **Imaging progress.** A new page tracks how many valid living ant species and subspecies are represented by specimen images in AntWeb and identifies those still lacking images. As of November 2026, more than 13,400 of 16,184 valid living species and subspecies (approximately 83%) have been imaged.
- **Specimens with label images only.** Specimens represented only by photographs of their labels, which often show the pinned ant as well, now appear after imaged specimens on species image pages and are marked "Label only." Label photographs are not counted as images of the ant.
- **Improved geographic links.** Links using alternative or historical country names, such as "USA," now redirect to the current geographic page.
- **Fossil Ants page.** Counts on the Fossil Ants page now correspond to the records displayed in their respective lists, with the same Valid and Curated views used elsewhere in AntWeb.

### AntWeb API version 4
**Important:** API version 3.1 has been retired. Existing scripts using v3.1 data endpoints must be updated.

API version 4 opened on 12 November 2026 at [https://www.antweb.org/v4/](https://www.antweb.org/v4/). Version 3.1 data requests now return HTTP 410 (Gone), directing users to the new API.

Major improvements include:
- **Free registered API keys.** Researchers and developers can register for a free key. Without a key, access is limited to 5 requests per minute, 50 requests per day, and 25 records per response. Registered users can make 60 requests per minute and 5,000 requests per day, with up to 500 records per response and 50,000 records per day.
- **Reliable pagination.** Responses say whether additional pages are available, and give the total number of matching records where it can be counted quickly. Specimen queries support cursor-based pagination using `afterCode`, making it easier to retrieve large datasets in successive requests.
- **Ant specimens by default.** Specimen-based queries now return Formicidae records by default. The parameter `allFamilies=true` also returns the other families in AntWeb (insects, spiders and other animals collected with ants).
- **Limits on long counts.** Long-running count requests are limited to protect server performance, with responses indicating when a count could not be completed and how users can proceed.
- **Documentation for automated users.** The API documentation, status endpoint, and [llms.txt](https://www.antweb.org/llms.txt) provide guidance for researchers, software developers, and AI applications.

For larger research projects, including taxonomic revisions, country inventories, and regional or global biodiversity analyses, please contact [antweb@antweb.org](mailto:antweb@antweb.org) to discuss data access and opportunities for scientific collaboration.

See the [API v4 announcement](https://github.com/calacademy-research/antweb/discussions/350) and the [API documentation](https://www.antweb.org/v4/).

### Improvements for curators and administrators
- **Upload and data-job monitoring.** A consolidated page displays uploads and data-processing jobs, including their progress, individual steps, and results.
- **Daily update monitoring.** Curators can now follow each stage of the daily database update, including completion times and processing results, through a page linked from Curator Tools.
- **Improved geographic assignments.** Specimens recorded under Ecuador with the state Galápagos, or under the United States with the state Hawaii, are automatically assigned to the appropriate island geographic unit during upload. Assignments use structured country and state fields rather than locality descriptions.
- **Improved handling of geographic names.** Uploads now preserve apostrophes in geographic names, including names from Yemen and Libya, while maintaining recognition of alternative regional names.
- **Species-list audit trail.** Removal of a species from a project list is now recorded with the reason for the change, improving traceability and data management.
- **Verified specimen data exports.** Administrators can generate complete specimen datasets for selected countries and share them with collaborators. Each export is checked against the database to verify completeness. The system also identifies separately treated island regions excluded from a selected country.

### Data quality and reliability
- **Faster daily updates.** Improvements to image-count calculations and data processing have reduced the daily update time from about 107 minutes to 80 (production, 11 and 14 November 2026).
- **Automated count validation.** Following each daily update, displayed counts are checked against their underlying lists. Discrepancies are reported to administrators for investigation.
- **Daily specimen-count updates.** Group specimen counts are now refreshed daily rather than only when new data are uploaded.
- **Improved GBIF image exports.** The archive AntWeb provides to GBIF now links each image at medium size, which GBIF can retrieve reliably.
- **Automated release testing.** After deployment, automated checks verify key AntWeb pages and API functionality to help identify problems quickly.

### Scientific collaboration and contributions
AntWeb is a community resource built through decades of field research, specimen identification, imaging, and data curation.

We encourage researchers using AntWeb data in taxonomic revisions, biodiversity inventories, and other publications to contact the AntWeb team early in their projects. We also welcome contributions of new specimen photographs, updated identifications, and type-specimen information from published research.

These contributions help keep AntWeb current and make new taxonomic knowledge accessible to the global research community.
